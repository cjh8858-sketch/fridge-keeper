# Items — 음식 관리

## 필드

| 필드     | 필수 | 입력                                                 | 기본값 |
| -------- | ---- | ---------------------------------------------------- | ------ |
| 이름     | ✅   | 텍스트 1–60자                                        |        |
| 유통기한 | ✅   | `<input type="date">` + 빠른 선택(+3일, +7일, +14일) |        |
| 보관위치 | ✅   | 냉장 / 냉동 / 실온                                   | 냉장   |
| 수량     |      | 1 이상 정수                                          | 1      |
| 분류     |      | 자유 텍스트 (유제품, 채소…)                          | 없음   |
| 메모     |      | 200자                                                | 없음   |

## 목록 화면

- 정렬: `sortByUrgency` (지남 → 오늘 → 임박 → 신선, 같은 상태는 날짜순)
- 상단 요약: "지남 N · 오늘 N · 임박 N" (각각 텍스트 포함)
- 필터: 보관위치 탭(전체/냉장/냉동/실온)
- 각 카드: 이름, 보관위치, 수량, 상태 배지, "먹음" 버튼

## 동작

- **먹음/버림 처리**: `consumed_at = now()` (삭제하지 않음 — 나중에 통계용). 3초간 "되돌리기" 토스트.
- **수정**: 카드 탭 → 폼
- **삭제**: 수정 화면 안에서만, 확인 필요
- 모든 변경은 같은 가족의 다른 기기에 실시간 반영

## 수용 기준

- [x] 유통기한 미입력·형식 오류 시 텍스트 오류 (지난 날짜는 허용 — 이미 지난 음식도 등록 가능)
- [ ] 추가 후 목록에서 올바른 위치에 표시
- [x] 오프라인이면 추가/수정·먹음 버튼 비활성 + "오프라인 — 읽기 전용 (… 기준)" 표시 → [pwa](../references/pwa.md)
