# Family Sharing

## 개념

- **가족(household)** = 하나의 냉장고 목록을 공유하는 그룹. 만든 사람이 `owner`.
- MVP는 사용자당 가족 1개.

## 흐름

**가족 만들기**: 로그인 후 가족이 없으면 "가족 만들기"(이름 입력) 또는 "초대코드로 참여" 선택 → `create_household` RPC.

**초대하기**: 가족 화면 → "초대코드 만들기" → 8자 코드 표시 + 복사/공유 버튼(Web Share API 지원 시) → 7일 후 만료.

**참여하기**: 코드 입력 → `join_household` RPC → 즉시 공유 목록 표시. 대소문자 무시.

**나가기 / 내보내기**: 구성원은 언제든 나가기(확인 창). owner는 구성원 내보내기. owner 본인은 MVP에서 나갈 수 없음 → TD-7.

## 수용 기준

- [ ] 다른 가족의 음식·초대코드·구성원은 어떤 경로로도 보이지 않는다 (RLS 테스트로 보장)
- [x] 만료/잘못된 코드는 "코드가 만료되었거나 올바르지 않습니다" 텍스트 오류
- [ ] 구성원 목록에 각자 이메일 첫 글자 아바타
- [ ] A 기기에서 추가한 음식이 B 기기에 새로고침 없이 3초 이내 표시 (`/verify-sync`)
