# Product Specs

**냉장고 지킴이** — 가족이 함께 쓰는 냉장고 유통기한 알림 웹앱. 휴대폰·PC 어디서든 같은 목록을 보고, 버리기 전에 먹는다.

## 대상 사용자

- 장보기·요리 담당 가족 구성원 (주 사용자, 휴대폰)
- 같은 집에 사는 다른 구성원 (가끔 확인·"먹음" 처리)

푸시 알림, 바코드 스캔, 영수증 인식, 레시피 추천, Google 로그인, 오프라인 편집.
