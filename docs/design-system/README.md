# Design System

"냉장고 앞에서 한 손으로" 쓰는 앱. **모바일 우선**, 정보는 "급한 것부터".

| 문서                                 | 내용                                                     |
| ------------------------------------ | -------------------------------------------------------- |
| [tokens.md](tokens.md)               | 색·간격·타이포·모양 토큰 (원본: `src/styles/tokens.css`) |
| [components.md](components.md)       | 컴포넌트 목록, 클래스명, 사용 규칙                       |
| [accessibility.md](accessibility.md) | 색 대비, 상태 표시, 터치 영역, 모션                      |

## 원칙

1. **급한 것이 먼저 보인다** — 목록은 `sortByUrgency` 순서, 지남/오늘 항목은 상단 요약.
2. **색만으로 말하지 않는다** — 상태 배지는 항상 텍스트(`D-2`, `오늘까지`, `3일 지남`) 포함.
3. **한 번의 탭** — 주요 동작(추가, 먹음 처리)은 엄지 영역(하단)에, 최소 44px.
4. **토큰만 사용** — 새 값이 필요하면 토큰을 먼저 추가(I8).

## 레이아웃

- 모바일(<768px): 1열 목록 + 하단 고정 추가 버튼
- PC(≥768px): 2열(목록 | 상세/추가 폼), 최대 폭 `--content-max`
- 다크 모드: `prefers-color-scheme`로 자동
