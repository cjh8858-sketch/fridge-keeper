# Accessibility

| 규칙               | 기준                                              | 확인 방법                 |
| ------------------ | ------------------------------------------------- | ------------------------- |
| 상태는 색 + 텍스트 | 배지에 `formatExpiryLabel()` 텍스트 필수          | 리뷰, E2E에서 텍스트 확인 |
| 대비               | 본문 4.5:1, 큰 글자·아이콘 3:1 (라이트·다크 모두) | 토큰 추가 시 대비 계산    |
| 터치 영역          | 최소 44×44px (`--tap-min`)                        | `/verify-sync` 모바일 뷰  |
| 포커스             | `:focus-visible` 링 유지, 제거 금지               | 키보드로 전체 흐름        |
| 폼                 | 모든 input에 `<label>`, 오류는 텍스트로           | E2E `getByLabel`          |
| 동적 알림          | 토스트·동기화 상태는 `role="status"`              |                           |
| 모션               | `prefers-reduced-motion` 존중 (base.css)          |                           |
| 언어               | `<html lang="ko">`                                |                           |
