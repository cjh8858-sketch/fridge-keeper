# Verify Sync

테스트 통과 ≠ 동작 확인. 사용자 관점으로 직접 돌려본다.

## 준비

1. `.env`가 있는지 확인. 없으면 `docs/references/supabase-setup.md`를 안내하고, 브라우저 확인은 "설정 안내 화면이 정상 표시되는지"까지만 한다.
2. dev 서버 실행: `.claude/launch.json`의 `dev` 구성(`npm run dev`, 포트 5173)으로 브라우저 패널 `preview_start`.

## 시나리오

| #   | 시나리오                           | 기대                                        |
| --- | ---------------------------------- | ------------------------------------------- |
| 1   | 모바일 프리셋(375×812)으로 첫 화면 | 가로 스크롤 없음, 헤더·상태 화면 표시       |
| 2   | 데스크톱 프리셋                    | 레이아웃 깨짐 없음                          |
| 3   | 탭 A(계정 A)에서 음식 추가         | 목록에 급한 순서대로 표시, 배지 텍스트 정상 |
| 4   | 탭 B(같은 가족 계정 B)             | 새로고침 없이 3초 내 반영                   |
| 5   | 탭 C(다른 가족 계정)               | 아무것도 보이지 않음                        |
| 6   | 네트워크 오프라인                  | 읽기 전용 표시, 추가 버튼 비활성 (M6 이후)  |

- 로그인은 매직링크라 실제 메일이 필요하다. 테스트 계정 로그인은 **사용자에게 요청**한다(에이전트가 남의 계정으로 로그인하지 않는다). 3–5번이 불가능하면 했던 범위와 못한 범위를 정확히 보고.
- 콘솔 에러(`read_console_messages`)와 실패한 네트워크 요청 확인.
