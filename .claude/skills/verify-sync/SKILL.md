# Verify Sync

테스트 통과 ≠ 동작 확인. 사용자 관점으로 직접 돌려본다.

## 준비

1. `.env`가 있는지 확인. 없으면 `docs/references/supabase-setup.md`를 안내하고, 브라우저 확인은 "설정 안내 화면이 정상 표시되는지"까지만 한다.
2. dev 서버 실행: `.claude/launch.json`의 `dev` 구성(`npm run dev`, 포트 5173)으로 브라우저 패널 `preview_start`. 배포본은 https://cjh8858-sketch.github.io/fridge-keeper/
3. 로그인은 매직링크라 실제 메일이 필요하다. **로그인은 사용자에게 요청**한다(에이전트가 사용자 계정으로 로그인하지 않는다).
   - 로그아웃 상태에서 화면만 볼 때: 콘솔에서 `HomeView({ me: { userId: 'preview', email: 'p@example.com' } })`를 `#view`에 붙여 미리보기(RLS가 빈 목록·저장 거부 → DB에 쓰이지 않음).

## 시나리오

| #   | 시나리오                                              | 기대                                     |
| --- | ----------------------------------------------------- | ---------------------------------------- |
| 1   | 모바일 프리셋(375×812)으로 첫 화면                    | 가로 스크롤 없음, 헤더·상태 화면 표시    |
| 2   | 데스크톱 프리셋                                       | 2열(목록 \| 패널), 깨짐 없음             |
| 3   | 음식 추가                                             | 목록에 급한 순서대로, 배지 텍스트 정상   |
| 4   | **같은 계정의 다른 기기/탭**에서 보기                 | 새로고침 없이 3초 내 반영                |
| 5   | 먹음 → 되돌리기                                       | 사라졌다가 복귀, 다른 기기에도 반영      |
| 6   | 오프라인(`navigator.onLine=false` + `offline` 이벤트) | "오프라인 — 읽기 전용", 추가·먹음 비활성 |

- 콘솔 에러(`read_console_messages`)와 실패한 네트워크 요청 확인.
- 3–5가 불가능하면(로그인 불가 등) 했던 범위와 못한 범위를 정확히 보고.

## 보고
